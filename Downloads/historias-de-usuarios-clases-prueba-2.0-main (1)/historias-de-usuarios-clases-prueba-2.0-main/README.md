
 Historias de Usuarios por Clases

Nombre: Florencia Moyano
Título del trabajo: Historias de Usuarios por Clases
Fecha: 25 de mayo de 2026

 Descripción

Este documento contiene el desarrollo de historias de usuarios organizadas por clases, con el objetivo de identificar las necesidades, funcionalidades y requerimientos de los distintos usuarios dentro del sistema analizado.

Las historias de usuario permiten describir de manera clara y sencilla qué necesita cada tipo de usuario y cuál es el valor que espera obtener al utilizar el sistema.
